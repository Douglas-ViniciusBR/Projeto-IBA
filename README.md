🔥 Landing Page – Igreja Batista Atos (Geisel, João Pessoa – PB)

Este projeto consiste no desenvolvimento de uma Landing Page para a Igreja Batista Atos, localizada no bairro Geisel, na cidade de João Pessoa – PB.

🎯 Objetivo
O objetivo principal da Landing Page é "atrair, acolher e informar novos visitantes", apresentando a igreja, seus valores cristãos e suas programações (como horários de cultos e atividades), incentivando as pessoas a conhecerem e participarem da comunidade.

🖥️ Sobre a Página
A página foi projetada para ser:
- Simples e objetiva  
- Moderna e responsiva  
- Clara nas informações  
- Acolhedora para novos visitantes  

Tudo isso com foco em facilitar o **primeiro contato** das pessoas com a igreja.

🛠️ Tecnologias Utilizadas
- React
- HTML  
- CSS  
- JavaScript  

Essas tecnologias foram utilizadas para construir uma interface leve, funcional, acessível e dirita ao ponto!
